# Binary Calculator

A simple and intuitive web-based binary calculator for number conversion and binary arithmetic operations.

## Features

- **Decimal to Binary Conversion**: Convert decimal numbers to binary representation
- **Binary to Decimal Conversion**: Convert binary numbers to decimal representation
- **Binary Addition**: Add two binary numbers
- **Binary Subtraction**: Subtract two binary numbers

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use

1. **Open the Application**
   - Open `index.html` in your web browser

2. **Decimal to Binary Conversion**
   - Enter a decimal number in the input field
   - Click "Konversi ke Biner" button
   - The binary result will be displayed

3. **Binary to Decimal Conversion**
   - Enter a binary number (only 0 and 1) in the input field
   - Click "Konversi ke Desimal" button
   - The decimal result will be displayed

4. **Binary Operations**
   - Enter two binary numbers
   - Click "Tambah" to add or "Kurang" to subtract
   - The result will be displayed in binary format
